# Депутат — кабинет Ивана Фомина

Персональный справочный сайт о работе в Канском окружном Совете депутатов.

## Содержимое

- Обзор и первые шаги (отметки хранятся на текущем устройстве).
- Сессии и комиссии: ползунок, фильтры, подробности и экспорт планового периода в ICS.
- Подтверждённые возможности мандата с первоисточниками.
- Устройство Совета и контакты.
- Оригиналы шести официальных документов, сохранённые 28 сентября 2026 года.

Точные даты будущих сессий не подтверждены. Указанные периоды взяты из плана на 2026 год, решение № 6-71 от 18.12.2025. ICS содержит STATUS:TENTATIVE и TRANSP:TRANSPARENT. Данные не обновляются автоматически.

Сайт открыт по ссылке, без авторизации. Формы отправки обращений и сбор персональных данных отсутствуют. Чек-лист использует только localStorage устройства.

## Запуск

Сайт не требует сборки. Подойдёт любой статический HTTP-сервер, например `python3 -m http.server 4193` из этой папки. GitHub Pages публикует корень ветки main.

## Изменение

`app.js` — информация и взаимодействия; `style.css` — оформление; `documents/` — официальные источники; `assets/` — фон. Данные должны меняться только после проверки актуальных документов. Сведения о роли Ивана Фомина предоставлены им самим 29.09.2026.
